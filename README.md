# BizWorx Health Check (app test)

A single-page, BizWorx-branded web app. A business owner enters four numbers (revenue, expenses, owner pay, cash) and gets a health score, profit margin, cash runway, and next steps, with a "Book a strategy call" CTA.

- No build step. Open `index.html` in a browser, or host it on any static host (GitHub Pages, Netlify).
- Logos in `assets/` come from the BizWorx Financial design system.
